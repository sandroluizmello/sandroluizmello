#### 🚀 Projetos em Destaque

**[copa-challenger-data-engineering](https://github.com/sandroluizmello/copa-challenger-data-engineering)**
Pipeline de dados completo ponta a ponta com dados históricos das Copas do Mundo FIFA: ingestão robusta → modelagem em Star Schema com **dbt** → 55 testes automatizados de qualidade → **CI/CD com GitHub Actions** (validação + build de integração) → **dashboard interativo com Streamlit** → **modelo preditivo de Machine Learning** (classificação de resultados + gols esperados). Ambiente 100% containerizado com Docker.

**[brazilian-ecommerce-data-lake](https://github.com/sandroluizmello/brazilian-ecommerce-data-lake)**
Pipeline de Engenharia de Dados completo utilizando PySpark, Airflow e MinIO (S3), implementando arquitetura Medallion (Bronze, Silver e Gold) em um ambiente semelhante ao de produção.
